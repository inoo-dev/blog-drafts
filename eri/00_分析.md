# えり 投稿の型の分析（2026-10-25）

調べた範囲：WebSearch（日本語）。TikTok・Instagramは中身まで直接は見られないため、公開されているまとめ記事と、案件で決まっている型（みさえさん @misae_43「日常系6枚」）から整理。数字は記事にあったもので、出典の検証方法が書かれていないため台本には使わない。

## 伸びる型の表

| 型 | 中身 | えりでの使い方 | 根拠 |
|---|---|---|---|
| 日常系6枚（時刻＋心の声） | 1枚1場面・短い一言。5枚目まで共感だけ | 全10本の基本の形 | みさえさん型（案件指定） |
| 冒頭フック | 問いかけ・意外な事実・目を引く絵で最初の数秒で止める | 1〜2枚目に「あるある」の一番痛い場面 | stock-sun 転職TikTok記事 |
| ストーリー型 | 困難→挑戦→成長→成果 | 接客のつらさ→事務を調べ始める→小さく前進。成果（内定・年収）は書かない | stock-sun |
| 1日密着型 | 働く1日を時刻で追う | 時刻表示がそのまま密着の形になる | stock-sun |
| ギャップ型 | 思っていたのと違う一面 | 「事務＝座ってるだけ」と思ってた、など職種解説 | stock-sun |
| 職種解説 | 仕事の中身を短く見せる | 固定ポスト・事務の1日 | 猪原さんロードマップ |
| 失敗注意 | 「これやると後悔」系。保存されやすい | 未経験可の落とし穴・求人の見方 | 猪原さんロードマップ |
| 面接・退職 | 不安が大きい場面。コメントが付きやすい | 面接の質問・退職の切り出し | 猪原さんロードマップ |
| 接客の痛み | 土日・立ち仕事・クレーム。見る人が自分ごとにする | 入口の本数を一番多く | 猪原さんロードマップ |

## 運用の目安
- 投稿：平日19〜22時、週末13〜15時が反応を得やすいとされる（stock-sun）。週3〜4本。
- ハッシュタグ：#転職 など大きい語＋#事務職 #接客業 など小さい語を混ぜる。
- コメントには早めに返す。
- 固定ポスト3本：01（自己紹介）・02（エージェント前の確認）・03（事務の仕事）。
- やらない：エージェントを使った／年収が上がった体験談、サブ垢の自作自演、他人の動画の再編集、同じ宣伝文の使い回し、1000人まではリンク・LINE・登録の案内。
