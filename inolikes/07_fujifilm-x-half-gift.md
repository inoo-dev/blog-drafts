# FUJIFILM X half を年末に贈るなら　「撮ったらすぐ見られない」が逆に楽しいカメラ

X half、やっぱりいいカメラだなって思います。

富士フイルムが2025年6月に出したコンパクトデジタルカメラ X half。縦長の写真、2枚を1枚にする「2in1」、撮った写真を現像するまで見られない「フィルムカメラモード」。スペックで勝負するカメラではなく、撮ること自体を楽しむためのカメラです。

【猪原さんの感想：X half を使っていて一番好きなところ（INOLIKESのX half記事とつなげる）】

年末のプレゼントや、1年がんばった自分へのご褒美として X half はどうなのか。公式情報をもとに、特徴と注意点を整理してみます。

## X half の基本スペック

| 項目 | FUJIFILM X half（X-HF1） |
|---|---|
| 発売日 | 2025年6月26日 |
| 価格 | オープン価格【要確認：現在の実売価格】 |
| 重さ | 240g（バッテリー・メモリーカード含む） |
| センサー | 1型 裏面照射型 |
| レンズ | 35mm判換算32mm相当 F2.8（単焦点） |
| モニター | 縦長3:4の背面液晶 |
| ファインダー | 縦長の光学ファインダー |
| フィルムシミュレーション | 13種類（REALA ACEなど） |
| 撮影可能枚数 | 光学ファインダー使用時 最大880枚 |

240gは、りんご1個分くらい。上着のポケットにも入りそうなサイズ感です。

32mm相当というのは、使い捨てカメラの「写ルンです」と同じ焦点距離だそうです。広すぎず狭すぎず、目で見た景色に近い感覚で撮れる画角です。

## 縦長で撮るのが基本のカメラ

📷 写真②：縦長の背面液晶（alt：FUJIFILM X half 縦長 背面液晶）

X half は、カメラを普通に構えると縦長の写真が撮れます。背面の液晶も、ファインダーも縦長。

これ、スマホで写真を見る今の時代には合っていると思います。スマホの画面いっぱいに写真が表示されるし、SNSにも載せやすい。

名前の「half」は、フィルムカメラのハーフサイズ（1コマを半分に使って縦長に撮る）から来ています。

## 2in1 と フィルムカメラモード

📷 写真③：2in1で撮った写真（alt：INOLIKES FUJIFILM X half 2in1 作例）

X half を「ほかのカメラと違う」と感じさせるのが、この2つの機能だと思います。

「2in1」は、縦長の写真を2枚つなげて1枚の写真にする機能です。左右に違う場面を並べると、ちょっとした物語みたいになります。ハーフサイズのフィルムカメラで、2コマが並んで現像されるあの感じです。

「フィルムカメラモード」は、液晶を見られなくして、36枚・54枚・72枚の「1本」を撮りきるまで写真を確認できないモード。撮りきると、まとめて見られるようになります。

今は撮ったらすぐ見て、ダメなら消すのが当たり前ですよね。でもこのモードだと、1枚1枚ちゃんと考えてシャッターを押すようになる。で、撮りきったあとにまとめて見る楽しみがある。これがフィルムカメラの楽しさなんですよね〜。

【猪原さんの作例：2in1 またはフィルムカメラモードで撮った写真】

## 写りを変える遊び

フィルムシミュレーションは13種類。REALA ACE など、富士フイルムのカメラでおなじみの色を選べます。

ほかにも、グレインエフェクト（粒状感）、光漏れ、ハレーション、期限切れフィルム風のフィルター、日付の写し込みなど、フィルムっぽい「味」を足す機能がたくさんあります。

日付の写し込み、年末年始の写真にはいいじゃんって思います！「2026.12.31」と入った写真って、何年か後に見返すとグッとくると思うので。

## 贈る前に知っておきたいこと

いいところばかりではないので、注意点も書いておきます。

まず、レンズは32mm相当の単焦点で、ズームはできません。遠くのものを大きく撮りたい人（運動会など）には向きません。

次に、センサーは1型。富士フイルムのXシリーズ（APS-C）と比べると小さいです。画質を一番に求める人には、ほかのカメラのほうが合うと思います。

そして価格。発売時の価格や現在の実売は時期で変わるので【要確認：贈る時点の価格】。「スマホで十分」と思っている人に贈ると、良さが伝わりにくいかもしれません。撮る過程を楽しめる人向けのカメラです。

【猪原さんの感想：使っていて気になったところ（INOLIKESのX half記事にあれば転記）】

## こんな人に贈るといいと思います

写ルンですやフィルムカメラが好きだった人、スマホの写真に少し飽きている人、日常をゆるく記録したい人。

カメラに詳しくなくても、フィルムシミュレーションを選んでシャッターを押すだけで雰囲気のある写真になるので、「カメラ初心者だけど、ちょっといいカメラがほしい」という人にも合うと思います。

## 一緒に贈りたいもの

X half を贈るなら、一緒に付けると喜ばれそうなものも考えてみました。

ひとつはストラップ。小さくて軽いカメラなので、手首に通すハンドストラップがあると、ポケットから出して撮るときに落としにくくなります。

もうひとつは、スマホプリンターの instax mini Link 3。X half の写真をスマホに送って、チェキのフィルムで出す。縦長の写真とチェキの組み合わせは、相性がよさそうだなって思います。フィルムカメラモードで撮りきった36枚から、お気に入りを何枚かプリントする、みたいな楽しみ方もできます。

あと、予備のバッテリーとメモリーカード。撮影可能枚数は光学ファインダー使用時で最大880枚とされていますが、液晶を使う撮り方だと減ると思うので【要確認：液晶使用時の撮影可能枚数】、旅行に持っていくなら予備があると安心です。

## まとめ

FUJIFILM X half は、高画質やたくさんの機能を求めるカメラではないです。

でも「撮ったらすぐ見られない」「縦に2枚並べる」みたいな、ちょっと不便な仕組みが、撮ることを楽しくしてくれる。そういうカメラだと思います。

1年の終わりに、来年たくさん写真を撮るための1台として。自分へのご褒美でもいいし、大事な人への贈り物でもいいと思います。
