「安く手に入るなら…」って考えたこと、ありますよね。

| リスク | 中身 |
|---|---|
| 品質 | 日本と同じ確認がされていない国もある |
| 表示 | 虚偽・誇大な表示がある |
| 偽造 | 正規品を装った偽物・不衛生な製造 |
| 副作用 | 情報が少なく対応が難しい |
| 救済 | 医薬品副作用被害救済制度の対象外 |
| 業者 | 代行業者が責任を負わないことがある |
| 承認 | 海外で承認されていても安全とは限らない |

## 一番ドキッとしたこと

救済制度の対象外。
何かあったとき、自分で全部背負うってことなんですよね。これはけっこう重い。

## 始める前に考えたいこと

- その薬は国内で処方してもらえるか
- 持病・飲んでいる薬を医師に伝えたか
- 副作用が出たとき、相談できる医師がいるか
- 処方薬は医師の処方が確認できないと個人輸入できない（厚労省の記載）
