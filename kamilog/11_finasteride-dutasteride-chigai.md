# フィナステリドとデュタステリド、添付文書で違いを表に

知恵袋を見ていると「フィナとデュタ、選ぶならどっち？」「切り替える場合ってどうなの？」という質問がけっこう出てきます。
僕はフィナステリドから始めて、途中でデュタステリドに変えました。今はデュタステリドとミノキシジルの併用です。
「どっちがいいか」は僕には言えません。決めるのは医師です。ただ、2つの薬が公式にどう書かれているかは、誰でも読めます。添付文書とガイドラインを並べてみた記録です。

## 選ぶならどっち、と聞かれても困る理由

「どっちが効くんですか？」って、僕も聞かれたら困ります（笑）
専門家じゃないし、効き方は人によって違うと思うので。

それに、僕が「変えてよかった」みたいなことを書くと、それは薬の効果の体験談になっちゃう。それはこのブログではやらないと決めています。

だからこの記事は、公式の資料に書いてあることだけを並べます。
自分の状態をどう判断するかは、表を持って医師に聞く。そのための下準備、くらいの位置づけです。

## 2つの薬の違いを表にした

ここが一番見返したいところです。PMDAの添付文書と、日本皮膚科学会のガイドライン（2017年版）から拾いました。

| 項目 | フィナステリド（プロペシア） | デュタステリド（ザガーロ） |
|---|---|---|
| ガイドラインの推奨度 | A | A |
| 女性への投与 | 妊婦・授乳中は禁忌、女性への適応なし | 女性は禁忌 |
| 子ども | 適応なし | 禁忌 |
| 重い肝機能障害の人 | 禁忌の記載なし【要確認】 | 禁忌 |
| 性機能の副作用の頻度 | リビドー減退1〜5%未満、勃起機能不全・射精障害は1%未満 | 性機能不全（リビドー減退・勃起不全・射精障害）1%以上 |
| 重大な副作用 | 肝機能障害（頻度不明） | 肝機能障害・黄疸（頻度不明） |
| PSAへの影響 | 約40%低下（国内24〜50歳）、2倍を目安に評価 | 約50%低下（前立腺肥大症の試験）、2倍して比べる |
| 割れた・漏れた薬への注意 | 粉砕・破損した錠剤を妊婦などが扱わない | 漏れた中身に女性・子どもが触れない |
| 献血の延期（日赤の表） | 1か月 | 6か月 |
| 飲み合わせの注意 | 「併用注意」の項目なし | CYP3A4を阻害する薬で血中濃度が上がるおそれ |

献血の期間は日赤の服薬一覧から【要確認：公的資料で再確認】。詳しくは /aga-kenketsu/ 【要確認：01のスラッグ公開後に実在確認】に書きました。

数字の書き方が違うので、そのまま比べて「こっちが少ない」と読まないこと。試験の人数も期間も違います。表は「何が書いてあるか」を並べただけです。

## 調べてみたらこうだった

調べた範囲で目に留まったのは、2つとも同じ仲間の薬だということ。どちらも5α還元酵素という酵素の働きを抑える薬です。
ガイドラインでは、デュタステリドは2型だけでなく1型の酵素も抑える、と説明されています【要確認：GL2017 CQ2の記述を原文で確認】。

あと、ガイドラインの書き方にも差がありました。
フィナステリドは「少なくとも6カ月程度は内服を継続し効果を確認すべき」とあって、日本人の長期の観察研究にも触れています。
デュタステリドは「1年を超える長期投与での効果や投与中止後の毛髪量変化については検討されていない」と書かれていました（2017年版の時点）。

新しい薬のほうが、長く飲んだときのデータが少ない。当たり前ですが、見落としやすい点です。

どっちも推奨度はA。でも、推奨度が同じでも中身の書き方は違う。ここは表だけ見てると見落とすところだなと。

副作用の数字も、試験の条件で見え方が変わります。
ザガーロの添付文書には、日本人のAGAの男性120人が52週飲んだ試験で、副作用が16.7%（120人中20人）、うち勃起不全10.8%、リビドー減退8.3%、射精障害4.2%と書かれています。
プロペシアの添付文書の長期試験（通算96週）では、期間中の副作用の発現率は1.1%（374人中4人）でした。

この2つを並べて「デュタのほうが多い」と読むのは、たぶん乱暴です。試験のやり方も期間も、数え方も違うので。
僕が言えるのは、「どちらにも性機能の副作用が書かれていて、中止後も続いたという報告もある」ということまで。気になる人は、数字を持って医師に聞くのがいいと思ってます。

それと、ザガーロの添付文書には健康な成人で精子の数が平均約23%減った試験の話も載っていました。全員が正常範囲内だったそうですが、妊活の話につながるので、それは別の記事で書きます。

## 切り替えを考える前に確認したいこと

知恵袋で多かったのが「フィナからデュタに切り替える場合」の質問です。
用量や切り替えの手順は、僕は書きません。それは医師の仕事です。

ただ、相談に行く前に自分で整理しておけることはあります。

- 今の薬をいつから飲んでいるか（6か月たっているか）
- 気になっている副作用があるか。いつからか
- 健診でPSAを測る予定があるか
- 献血をする習慣があるか（延期の期間が変わる）
- 妊娠中・妊娠を考えているパートナーがいるか
- ほかに飲んでいる薬があるか（市販薬も）

最後の2つは、デュタステリドの添付文書を読むとかなり大事だとわかります。
自分で勝手に変える、勝手に足す、はやらない。変更は医師に相談してからです。

## 2択で迷ったときの見方

ここは僕なりの整理です。「どっちがいい」ではなく「何を聞けばいいか」の表。

| 気になること | 医師に聞くこと |
|---|---|
| 長く飲んだときのデータ | それぞれ、どのくらいの期間のデータがあるか |
| 性機能の副作用 | 自分の場合、どちらがどう影響しそうか |
| 健診のPSA | 測るとき、どう伝えればいいか |
| 家族への影響 | 家での保管で気をつけること（/dutasteride-kazoku/ 【要確認：09のスラッグ】） |
| 費用 | 自分の通う所での値段（薬によって違う） |

表を持っていくと、診察の短い時間でも話が早いです。

あと、添付文書を読むときの注意点も書いておきます。

- 頻度は「どの試験で、何人中何人か」を見る。数字だけ抜き出さない
- 「頻度不明」は「起きない」ではない。市販後の報告などで数を出せない、という意味
- 「中止後も持続したとの報告がある」と書かれた副作用は、両方の薬にある
- 女性・子どもへの注意は、自分が飲まなくても家族に関わる

最後のは特に、家に置いておく以上は知っておきたいところです。
添付文書はPMDAのサイトで誰でも無料で読めます。最初は漢字が多くて読みにくいですが、「禁忌」「重要な基本的注意」「副作用」の3か所だけ見れば、だいたいの形はつかめると思ってます。

もう1つ。ネットのクリニックのコラムでは、副作用の数字が丸められていたり、試験の条件が抜けていたりすることがあります。悪気はないんだと思うけど、元の添付文書に戻ると「あ、これ前立腺肥大症の人の試験なんだ」と気づくことがある。孫引きではなく原文に当たると、変に怖がったり変に安心したりすることが減らせると思います。

## 周りの話で薬を決めない

美容室には2ヶ月に1回行っています。

美容室や周りの人から薬の話を聞くことがあっても、それで自分の薬を決めるのは避けたいところです。人によって合う合わないがあるし、決めるのは処方する医師だと思ってます。

## 今の結論

僕はデュタステリドを皮膚科で処方してもらって、飲み続けています。
どっちを選ぶかは、自分の状態と医師の判断次第。表は、その相談のための道具です。

薬の量・飲み方・切り替え・やめるかどうかは、必ず医師に相談してください。
