# スマホの写真をチェキにしたい。instax mini Link 3 とチェキカメラ、どっちがいい？

写真、スマホに何千枚も入ってるのに、ほとんど見返してないんですよね。

僕も富士フイルムのカメラで撮った写真をスマホに送って、そのまま放置しがちです。そういう「データのまま眠っている写真」を、チェキのフィルムに出してくれるのが instax mini Link 3 です。

クリスマスや年末は、写真を手渡しする機会が増える時期。チェキのカメラを買うか、スマホプリンターにするか迷っている人向けに、mini Link 3 の特徴を整理してみます。

## instax mini Link 3 ってどんなもの？

📷 写真①：mini Link 3 本体とスマホ（alt：INOLIKES instax mini Link 3 スマホプリンター 外観）

スマホとBluetoothでつないで、写真をチェキのフィルム（instax mini）にプリントする小さなプリンターです。カメラ機能はありません。

## アプリでできることが多い

📷 写真②：アプリ画面（alt：INOLIKES instax mini Link 3 アプリ 画面）

mini Link 3 は本体よりも、アプリの機能が多いのが特徴です。公式サイトに載っているものをまとめると、こんな感じ。

まず、動画からベストショットを切り出してプリントできます。子どもの動画から一瞬を選べるのは、地味にありがたい機能だと思います。

「Click to Collage」は、3秒おきに6カット連続で撮って、2〜6分割のコラージュにする機能。プリクラっぽい遊び方ができます。

「instax AiR Studio」は、3D ARのエフェクトで、スマホの中に飾りつけた空間を作って撮影する機能。

「Remote Live View」は、離れた場所の人と撮影の様子を共有できる機能で、プリンターの電源ボタンをシャッター代わりにもできるそうです。

ほかにも、撮影の様子を動画で残せるQRコード付きプリント、フレームプリント、コラージュプリント、相性診断、プリンターを傾けてズームする「instax Camera」機能など。正直、全部使いこなせる気はしません（笑）

## チェキカメラとどっちを選ぶ？

📷 写真③：mini Link 3 とチェキカメラを並べた写真（alt：INOLIKES instax mini Link 3 チェキ 比較）

ここが一番迷うところだと思います。

mini Link 3 が向いているのは、「もう撮った写真を出したい人」です。スマホやカメラで撮った中から、気に入った1枚だけを選べる。フィルムを無駄にしにくいです。価格も、ハイブリッド系のチェキカメラよりだいぶ安い。

チェキカメラが向いているのは、「その場で撮って、その場で渡したい人」。シャッターを押したらすぐ出てくるライブ感は、プリンターにはないところです。

両方ほしい人には、スマホの写真もプリントできるハイブリッド系（mini Evo や mini Evo Cinema など）という選択肢もあります。ただ価格は上がります。

僕なら、富士フイルムのカメラで撮った写真を出したいので、プリンターを選ぶかなって思います。せっかく色を作って撮った写真を、チェキの質感で見てみたい。

【猪原さんの感想：X-E5やX halfで撮った写真をチェキで出したい気持ちがあれば】

## クリスマス・年末の使い道

年末に使えそうな場面を考えてみました。

ひとつは年賀状やクリスマスカードに1枚貼る使い方。チェキのサイズは名刺くらいなので、カードに貼るとちょうどいい大きさです。

もうひとつは、帰省したときに祖父母へ孫の写真を渡す使い方。スマホで見せるより、紙で渡したほうが手元に残ります。

あとは忘年会。みんなで撮った写真を、その場でプリントして配れます。

## 気になるところ

まず、フィルム代がかかること。1パック10枚で、1枚ごとにお金がかかります。普通の写真プリントより割高なので、何でもかんでもプリントするものではないです。

次に、チェキのフィルムは画面サイズが小さいこと。風景の細かいところは分かりにくいです。人の顔や、シンプルな構図の写真のほうが映えると思います。

それと、カメラ機能はないので、プリンター単体でその場の写真は撮れません（スマホで撮ってからプリントする流れ）。

## よくある疑問

**どのフィルムを使う？**
instax mini フィルムです。公式サイトに載っている mini フィルムは15種類あって、どれも1パック10枚入り。ホワイトやブラックのほか、柄のあるものもあります。SQUARE や WIDE のフィルムは使えないので注意してください。ワイドで出したい人には別のプリンター（instax Link WIDE 2）があります。

**iPhone でも Android でも使える？**
専用アプリでつなぐ仕組みです。対応OSのバージョンは公式で確認してください【要確認：対応OS】。

**カメラで撮った写真もプリントできる？**
カメラの写真をいったんスマホに送れば、アプリからプリントできます。富士フイルムのカメラなら、スマホへの転送アプリを使う流れになります。

**カラーは？**
CLAY WHITE、SAGE GREEN、ROSE PINK の3色です。どれも落ち着いた色なので、大人への贈り物にも選びやすいと思います。

## まとめ

instax mini Link 3 は、スマホに眠っている写真を「手渡しできる1枚」にしてくれる道具です。

撮る楽しさはチェキカメラのほうがあるけれど、選んで出す楽しさはこっち。すでにカメラやスマホでたくさん撮っている人には、こっちのほうが満足度は高いと思います〜。

価格も手ごろなので、ブラックフライデーやクリスマスのセールで見かけたら、候補に入れていい1台です。
